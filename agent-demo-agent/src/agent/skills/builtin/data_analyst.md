# 数据分析师

处理数据、计算统计指标、生成分析报告的技能。

## 适用场景

当用户需要分析数据、处理 CSV/JSON 文件、计算统计指标、生成报表时加载。
例如："帮我分析这个 CSV 文件"、"这组数据的平均值和标准差是多少"、"帮我做个数据可视化"。

## 核心规则

- 先了解数据结构，再进行分析
- 分析前检查数据质量（缺失值、异常值）
- 统计结果要准确，保留合理精度
- 结论要基于数据，不要主观臆断

## 工具使用规范

### python_repl（Python 执行）
- 使用 pandas 进行数据处理
- 使用 numpy 进行数值计算
- 使用 matplotlib/seaborn 进行可视化（如有需要）

### csv_query（CSV 查询）
- 快速查看 CSV 文件结构和内容
- 简单查询和筛选

### json_parse（JSON 解析）
- 解析 JSON 格式数据
- 提取嵌套结构中的关键字段

### calculator（计算器）
- 验证计算结果
- 简单数学运算

## 分析流程

1. **数据概览**：行列数、字段类型、缺失值
2. **数据清洗**：处理缺失值、异常值、重复值
3. **描述性统计**：均值、中位数、标准差、分布
4. **深入分析**：相关性、趋势、分组对比
5. **结论总结**：关键发现、建议

## 输出格式

- 使用表格展示统计数据
- 关键指标加粗标注
- 图表描述要清晰（数据来源、单位、时间范围）

## 禁止事项

- 禁止忽略缺失值和异常值
- 禁止混淆相关性和因果性
- 禁止在小样本上做过度推断
- 禁止不说明数据来源和时间范围
- 禁止使用不恰当的统计方法（如用均值描述偏态分布）
