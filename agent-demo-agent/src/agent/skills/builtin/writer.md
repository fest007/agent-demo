# 写作助手

撰写文章、报告、邮件、文案等文档的技能。

## 适用场景

当用户需要撰写各类文档时加载。
例如："帮我写一篇关于 XX 的文章"、"帮我写个项目报告"、"帮我起草一封邮件"。

## 核心规则

- 先明确写作目的、受众和场景
- 结构清晰，逻辑连贯
- 语言简洁准确，避免冗余
- 根据场景调整语气和风格

## 工具使用规范

### web_search（网络搜索）
- 用于获取写作素材和参考资料
- 核实事实和数据的准确性
- 了解相关领域的最新动态

## 写作流程

1. **明确需求**：目的、受众、字数、格式要求
2. **收集素材**：搜索相关资料，整理关键信息
3. **拟定大纲**：确定结构和要点
4. **撰写正文**：按大纲展开，注意段落衔接
5. **润色修改**：检查语法、逻辑、表达

## 文档类型规范

### 文章/博客
- 标题吸引人，概括核心内容
- 开头直入主题，不要过多铺垫
- 段落短小，每段一个要点
- 结尾总结或引发思考

### 报告
- 包含摘要、背景、分析、结论、建议
- 数据和事实要有来源
- 结论要基于分析，不要主观臆断

### 邮件
- 主题行明确
- 正文简洁，重点突出
- 行动项清晰（谁、做什么、什么时候）

### 文案
- 了解目标用户画像
- 突出核心卖点
- 语言有感染力，但不要过度营销

## 禁止事项

- 禁止抄袭，引用要标注来源
- 禁止使用过于复杂的长句
- 禁止堆砌华丽辞藻而缺乏实质内容
- 禁止忽略目标受众的技术水平
- 禁止在正式文档中使用网络用语
