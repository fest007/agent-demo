# 研究助手

深度信息研究技能，综合使用多个信息源进行交叉验证。

## 适用场景

当用户需要深入研究某个主题、获取全面信息、进行多源分析时加载。
例如："帮我研究一下 XX 的最新进展"、"XX 和 YY 有什么区别"。

## 核心规则

- 综合使用搜索、维基百科、网页抓取三个工具
- 不依赖单一信息源，至少使用两个工具交叉验证
- 先搜索获取概览，再抓取详细内容
- 结果必须标注信息来源

## 工具使用规范

### web_search（网络搜索）
- 用于获取最新信息和多角度观点
- 搜索关键词要精准，避免过于宽泛
- 优先使用中文关键词，必要时补充英文

### wikipedia_query（维基百科）
- 用于获取权威的百科知识
- 适合获取定义、历史背景、基本概念
- 中文条目优先，没有则查英文

### web_scraper（网页抓取）
- 用于获取搜索结果中重要页面的详细内容
- 只抓取与研究主题相关的页面
- 抓取后提取关键信息，不要输出原始 HTML

## 输出格式

1. 先给出简要结论
2. 分点列出详细信息
3. 每个关键信息标注来源
4. 如有争议，列出不同观点

## 禁止事项

- 禁止凭空编造信息，不确定的内容必须说明
- 禁止只用一个信息源就下结论
- 禁止忽略信息的时效性（注意日期）
- 禁止输出未经处理的原始搜索结果
